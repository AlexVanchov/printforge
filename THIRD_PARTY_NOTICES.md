# Third-party software in PrintForge

PrintForge bundles the following open-source components:

| Component | Use | License |
|---|---|---|
| [Solemn](https://github.com/AlexVanchov/solemn) runtime and webview glue | the app is written in Solemn and compiled with its toolchain | Apache-2.0 |
| [three.js](https://github.com/mrdoob/three.js) | 3D viewport | MIT |
| [Manifold](https://github.com/elalish/manifold) (`manifold-3d`) | geometry kernel (booleans, watertight meshes) | Apache-2.0 |
| Droid Sans Bold (via three.js `examples/fonts/droid`) | 3D text | Apache-2.0 |

The full license texts are available at the linked project pages.
